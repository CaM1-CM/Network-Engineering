# Network Engineering

Welcome to my personal Network Engineering repository!

This repository documents my hands-on networking labs,
configurations, troubleshooting scenarios, and technical learning.

## Areas of Focus

- Routing: OSPF, BGP, static routing
- Switching: VLANs, STP, inter-VLAN routing
- Network Security: ACLs, firewalls, VPNs
- High Availability: HSRP, redundancy and failover
- Troubleshooting: Network connectivity, routing and performance

## Purpose

The goal of this repository is to improve my practical networking
skills, document troubleshooting approaches, and share what I learn
while working with different networking technologies.
